# 🔐 Random Password Generator

A simple Python-based Random Password Generator that creates random passwords using uppercase letters, lowercase letters, numbers, and special characters.

This project helps users generate multiple passwords with a customized length, making it easier to create strong and unique passwords.

## 🚀 Features

* Generate multiple random passwords.
* Customize the password length.
* Includes uppercase letters (A–Z).
* Includes lowercase letters (a–z).
* Includes numbers (0–9).
* Includes special characters (!@#$%^&).
* Simple and user-friendly command-line interface.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Module:** Random (Python Standard Library)

## ⚙️ How It Works

1. Run the Python program.
2. Enter the number of passwords you want to generate.
3. Enter your required password length.
4. The program generates random passwords using a combination of letters, numbers, and special characters.
5. View your generated passwords in the terminal.
